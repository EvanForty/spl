launch anything

A memecoin community can deploy a staking vault, a vesting schedule and an automated treasury in an afternoon, without hiring a developer.

Every program gets a public profile with its deployment address, verified source code, transaction history and usage stats.

  • immutableTemplates deploy with no upgrade authority by default, so nobody can change the code later.
  • disclosedIf you keep upgrade authority, every program page shows it in plain sight.
  • auditedTemplates must pass a security audit before they're listed.
  • reviewedCustom program generation needs extra security review before it's offered.

The flywheel

More programs mean more usage. Usage means fees. Fees fund buybacks.

  1. →More programs launched. Each one is working infrastructure on Solana.
  2. →More on-chain program usage. Other projects integrate the programs and use them.
  3. →More deployment + marketplace fees. Deploys and template sales earn the platform fees.
  4. →Revenue funds $SPL buybacks. A share of fees buys the token on the open market.
  5. →More developers + templates. Template creators earn, so more of them build.

Buybacks depend on actual fee revenue and aren't guaranteed.

how SPL makes money

deployment fees

A small fee each time a program is deployed.

marketplace commissions

A cut when someone deploys a template another developer published.

premium templates

Advanced programs with more options, priced per deploy.

$SPL discounts

Holders pay lower deployment and marketplace fees.
